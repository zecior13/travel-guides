# Namibia – interaktywna lista pakowania

Prosta offline checklista do pakowania na wyprawę 4×4 po Namibii.

## Pliki

- `index.html` – strona główna
- `styles.css` – wygląd
- `data.js` – lista rzeczy do spakowania
- `app.js` – logika odhaczania, filtrów i zapisu postępu

## Jak używać lokalnie na iPhonie

1. Pobierz repozytorium jako ZIP z GitHuba.
2. Rozpakuj w aplikacji **Pliki**.
3. Otwórz `index.html` w Safari.
4. Odhaczaj rzeczy. Postęp zapisuje się lokalnie w przeglądarce.

## Uwaga

Postęp jest zapisany w `localStorage`, czyli lokalnie na urządzeniu/przeglądarce. Nie synchronizuje się automatycznie między urządzeniami.
