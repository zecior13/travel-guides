# Pescara Weekend PWA — 7–9.08.2026

Lekka aplikacja mobilna / PWA przygotowana do używania na iPhonie również offline.

## Najprostsze uruchomienie online + offline: GitHub Pages

1. Utwórz nowe publiczne repozytorium GitHub, np. `pescara-weekend`.
2. Wgraj **zawartość tego folderu** do głównego katalogu repozytorium (`index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, folder `assets`).
3. GitHub → repo → **Settings → Pages**.
4. `Build and deployment` → **Deploy from a branch** → `main` / `(root)` → Save.
5. Otwórz wygenerowany adres w Safari na iPhonie.
6. Safari → Udostępnij → **Dodaj do ekranu początkowego**.
7. Przed wyjazdem otwórz wszystkie zakładki aplikacji przy połączeniu z internetem.

Service worker zapisuje lokalnie cały plan, CSS, JS i zdjęcia. Google Maps, aktualne rozkłady i strony rezerwacyjne są zewnętrzne i do ich otwarcia potrzebny jest internet.
